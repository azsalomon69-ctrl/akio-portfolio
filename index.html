01 / 02

ACE Clock In/Out

A web-based time tracking and workforce management system built for ACE Outsource Solutions. Employees clock in and out of shifts, track breaks, and log which project they're working on; administrators see it all in real time.

Handles the full workflow: onboarding, schedules, projects, corrections, reports, and an audit trail of every admin action. Runs entirely in the browser, no install required, with a mobile-first experience for employees.

Time-entry integrity is enforced at the database level, not the client. All writes go through the API with server-side role checks and Row Level Security, so concurrent requests can't produce wrong numbers.

DonutSMP Hub

A community-built companion site for the DonutSMP Minecraft server, live player counts, rules, store info, and leaderboards in one clean, fast place. No game launch, no digging through Discord.

Built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step. Dark Minecraft-inspired aesthetic with a spinning donut favicon, click sounds, and smooth page transitions.

Player counts pull from mcstatus.io every 60 seconds. All 25 rules sit in a searchable accordion, the store mirrors every rank and shard package, and leaderboards hit the official DonutSMP API through a small backend proxy.
