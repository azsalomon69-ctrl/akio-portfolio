Recruitment ApplicationFull-stack · AI-assisted platform

Application overview

Faster applicant review for recruitment teams.

This web application helps HR teams, administrators, and company leadership review applicants without checking every submission manually. Recruitment teams create client campaigns, define the criteria for each role, and review candidates through a centralized dashboard.

The AI-assisted workflow assesses submitted résumés or portfolios, identifies strengths and gaps, measures suitability against campaign requirements, and can surface a potentially better campaign match when an applicant is not suitable for the original role.

My contribution

Frontend interfaces, backend and API development, database integration, and security-related implementation.
